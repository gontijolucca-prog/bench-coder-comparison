Veredito — Melhor CLI para delegar no Hermes Agent

Critérios para delegação no Hermes: funciona em modo headless, suporta MiniMax-M3, qualidade de output, velocidade, e fiabilidade de tool calling.

Vencedor: Claude Code 2.1.209

O Claude Code é o melhor CLI para delegação no Hermes Agent por estas razões:

1. Design superior: Produziu a landing page mais polida — gradientes em camadas, noise texture, tipografia com contraste 200/900, grid assimétrico, animações de reveal. Segue regras de design automaticamente via CLAUDE.md.

2. Fiabilidade: Funciona em modo headless (-p flag), suporta MiniMax-M3 via endpoint Anthropic-compatible, tool calling nativo sem issues. Build sempre limpo.

3. Autonomia: --dangerously-skip-permissions permite correr sem intervenção. --max-turns 50 dá margem para tarefas complexas.

4. Conhecimento de contexto: Lê CLAUDE.md/AGENTS.md automaticamente, pelo que respeita as regras de design do utilizador sem prompting extra.

2º lugar: Pi — Mais rápido (1.5 min), build sempre limpo, tool calling nativo com MiniMax-M3. Bom para tarefas rápidas e directas. Menos polido em design.

3º lugar: OpenCode — Rápido, brutalist design interessante, boa integração com MiniMax. Empata com Pi em velocidade.

4º lugar: Codex — Sólido mas lento. Precisa de PTY em macOS. Design convencional.

5º lugar: Aider — Funciona com --architect mode mas MiniMax-M3 não conforma bem com o formato de edit. Nomes de ficheiros corrompidos. Não recomendado para delegação automática.

6º lugar: Gemini CLI — Não suporta MiniMax-M3. Quota limitada. Design genérico. Não viável para este caso de uso.

7º lugar: Kilo Code — Bug crítico em modo headless. Não funciona para delegação automática.

Recomendação para o Hermes Agent: Usar Claude Code como CLI de delegação principal (mais qualidade, mais fiável). Usar Pi como alternativa rápida para tarefas simples. Evitar Kilo Code e Gemini CLI em modo automático.

PROMPT.md — Prompt enviado a todos os CLIs

Create a landing page for a fictional product called "NebulaTask" — a task management app for remote teams.

Requirements:
1. React + Vite + TypeScript + Tailwind CSS
2. Hero section with: product name, tagline, and a CTA button "Start Free Trial"
3. Three feature cards with icons (use emoji or SVG):
   - "Smart Prioritization" — AI ranks your tasks automatically
   - "Team Sync" — Real-time collaboration across timezones
   - "Deep Focus Mode" — Block distractions with one click
4. A stats bar with 3 numbers: "50K+ teams", "4.9/5 rating", "120+ countries"
5. A footer with: "NebulaTask" logo text, copyright "© 2026 NebulaTask Inc.", and 3 fake links (About, Pricing, Contact)
6. The page must compile with `npm run build` with zero errors
7. Use a modern, polished design — not generic. Pick a distinctive color scheme (not default Tailwind blue).
8. Make it responsive (mobile + desktop)

Do NOT add any extra features beyond what is listed above. Keep it clean and minimal.

When done, run `npm run build` to verify it compiles.
